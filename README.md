## Featured projects

### [AutoRelay](https://github.com/JakubLewosz/AutoRelay) — solo full-stack portfolio project

A webhook-driven automation platform that evaluates a safe conditional rule and delivers one retryable HTTP or Discord action. It combines a FastAPI API, PostgreSQL-backed sessions and execution queue, a separate worker, and a responsive React dashboard, with documented authorization, encryption, CSRF, and SSRF protections.

**Python · FastAPI · PostgreSQL · SQLAlchemy · Alembic · React · TypeScript · Docker Compose · GitHub Actions**

### [ElektroScan](https://github.com/JakubLewosz/ElektroScan) — flagship project · active development

A web application that demonstrates computer-vision-assisted analysis of electrical plans in PDF format, including symbol detection and counting.

> The public repository contains an earlier showcase version of ElektroScan. A substantially improved version is currently being developed privately by a two-person team.

Both team members share responsibilities across the backend, frontend, computer vision, testing, and documentation. The public version uses Python, FastAPI, Pydantic, OpenCV, PyMuPDF, NumPy, Server-Sent Events, React, TypeScript, Vite, Tailwind CSS, Playwright, Docker Compose, and GitHub Actions.

### [CodeFabric](https://github.com/JakubLewosz/CodeFabric) — solo project · completed prototype

A prototype for AI-assisted software project generation. A user describes a new application or requested change; CodeFabric prepares a plan for approval or revision, generates or edits project files, and performs an LLM-based review against the approved plan. It uses locally or privately hosted Ollama models through a Streamlit interface and a LangGraph workflow.

I originally developed CodeFabric during my 150-hour internship at the Office of the Polish Financial Supervision Authority (UKNF) and later refined it independently. **CodeFabric was developed as an individual internship project and was not an official product or production system of the Office of the Polish Financial Supervision Authority.**

### [Samurai's Last Stand](https://github.com/JakubLewosz/samurais-last-stand) — three-person team project

A 2D action game created for GameJamPlus Poland 2024/25 with Godot 4 and GDScript, representing 100 hours of documented project work. I shared responsibility for gameplay programming, testing, level development, and iterative improvements in a three-person team.

This repository is a fork of the original team repository and is kept on my profile to document my contribution to the project.
